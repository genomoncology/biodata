# BioData

BioData is a free, open-source Rust library of typed biomedical values: genes, variants, diseases, drugs, clinical trials and articles, with their parsers and JSON schemas. BioMCP builds on it.

BioData 1.0 merges the data-model crates of two consumers, BioMCP and a second consumer, and ships with BioMCP 1.0. Later releases add patient-level values read from FHIR and OMOP.

The plan lives in `sdlc/plan.md`. The license is MIT.
